# Machine Learning From Scratch

A learning repository documenting my journey of understanding machine learning from first principles, with a focus on the mathematical foundations behind machine learning algorithms.

Rather than treating machine learning as a collection of libraries and APIs, this repository focuses on understanding the mathematics, intuition, and implementation behind the algorithms.

## Learning Roadmap

* Linear Algebra
* Calculus
* Probability
* Statistics
* Machine Learning Algorithms
* Deep Learning

## Learning Approach

For each topic, I aim to combine:

1. **Mathematical intuition**
2. **Conceptual understanding**
3. **Python implementation**
4. **Solved exercises**
5. **Practical examples**

The goal is to understand not only how an algorithm works, but also why it works.

## Why This Repository?

My academic background is in Statistics, so I am particularly interested in understanding the mathematical foundations underlying machine learning.

This repository serves as a record of that progression from mathematical foundations to practical machine-learning implementations.
